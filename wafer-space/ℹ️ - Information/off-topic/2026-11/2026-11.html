I have to say, modern agent AIs are pretty awesome at smoke testing chips. My breakout board has a small MCU on it (acts as bootloader for my chip lol) and USB connection. So the test cycle is: write test for X functionality, transfer program to MCU, it flashes my chip then waits for response over serial, forwards back to PC for evaluation. The agent is slowly working through all the instructions and constructing tests for expected behavior and edge-cases. It also executes the tests against the RTL as a comparison. Already found a few very silly bugs in the hardware (and confirmed a few I already knew about). I was going to do some of this testing for my self, but being able to automate testing of all major functionality is pretty rad
