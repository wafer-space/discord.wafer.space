[2026-09-17 7:08 a.m.] mole99
Hi @Simo6572,

Was your previous chip created using the same GF180MCU process and a proprietary PDK, or did you use a different process?

Note that the foundry-provided standard cell library in the open-source PDK uses the high-voltage transistors, which are slow. Tholin made a community-created standard cell library using the low-voltage transistors, which is much faster running at 3.3V. However, it hasn't been tested yet (the wafers are coming out of the fab this week).
