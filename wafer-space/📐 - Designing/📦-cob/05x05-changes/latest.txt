[2026-09-27 7:45 a.m.] rebelmike
Well AIUI everyone with a quarter slot on run 2 is free silicon, so doing something a bit experimental with it is presumably ok.

One issue with quarter slot on run 3 is the price of the CoB is almost as much as the silicon, so if that could actually be reduced in some way that would be a good thing.

My understanding the way testing is setup is it would just be a different carrier board in the test board, and due to the low number of mating cycles, that board is consumable anyway. (As an aside, if the Hirose part has more mating cycles then for the other boards you might save money using that!)

On the other hand, it would introduce complexity and possible confusion, e.g. we’d need different example breakouts and people would need to pick the right one. I could see the quarter slot being different ending up as annoying and it also being slightly unreliable due to the cheap part.

Overall if I were you I would probably not want to do it, just to keep things simple, but it depends how much trying to reduce the cost is a factor.
