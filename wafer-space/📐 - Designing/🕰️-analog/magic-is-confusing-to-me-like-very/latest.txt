[2026-09-30 7:18 a.m.] bailey8889
Oh, are you using the same script for LVS extraction and PEX extraction? Maybe you want to divide those, or at least use different magic scripts.

BTW, I think the flattening above does NOT propagate lower hierarchy text to the top, so there's no problem with local naming of nets (if I understand your comment).

These are the commands that I use for hierarchical extraction for LVS.
```
drc off
crashbackups stop
gds drccheck off
undo disable
locking disable
gds flatten yes # flattens cells with less than 10 shapes
gds flatglob <cellname> # repeated for other larger cells to be flattened before extracting. Note: All subcells must be explicitly flattened too.
gds read <gdsfile>
load <cellname>
select top cell
expand
extract no all ;# clear all flags
extract do aliases
extract do local
extract unique
ext2spice lvs
ext2spice merge conservative ;# reduce parallel devices
ext2spice short resistor ;# keep both ports but connect them with a 0 ohm resistor
ext2spice -o <cellname>.gds.spice <cellname>.ext
feedback save <cellname>.feedback.txt
```

Fun fact: magic's default extraction connects virtual nets by name - disjoint nets with the same label are extracted as connected. 
Use `extract unique` to automatically add a `_uq*` suffix to unconnected duplicate labels.
