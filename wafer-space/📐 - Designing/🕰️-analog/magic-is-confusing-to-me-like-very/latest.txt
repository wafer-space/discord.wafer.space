Ok, the `extract_spice_simplified.py` file, right?

I think these commands will yield a flattened parasitic extracted netlist with a hierarchical layout as input.
It also turns off some of the backup processing that may speed things up. The `short resistor` directives adds a 0Ω resistor between shorted ports instead of dropping them. And the `feedback save` will save any extraction anomalies (text problems, etc.).

```
        magic_commands = [
            "drc off",
            "gds drccheck off",
            "undo disable",
            "locking disable",
            "crashbackups stop",
            f"gds read {tcl_brace(temp_gds)}",
            f"load {tcl_brace(top_cell)}",
            "select top cell",
            "port makeall",
            "expand",
            f"flatten {tcl_brace(top_cell)}_flat",
            f"load {tcl_brace(top_cell)}_flat",
            f"cellname delete {tcl_brace(top_cell)}",
            f"cellname rename {tcl_brace(top_cell)}_flat {tcl_brace(top_cell)}",
            "select top cell",
            "ext2spice lvs",
            "ext2spice rthresh 0",
            "ext2spice merge conservative"
            "ext2spice short resistor"
            "extresist simplify on",
            "extresist minres 100",
            "extresist threshold 1000",
            "extract do resistance",
            "extract all",
            "ext2spice extresist on",
            "ext2spice resistor tee on",
            "feedback save {tcl_brace(top_cell)}.pex.feedback.txt",
        ]
```

Haven't tested, just added some of the commands from my scripts and Tim's comments.
