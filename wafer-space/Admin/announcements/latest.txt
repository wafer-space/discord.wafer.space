# Wafer Delay for Run #2

Hi @everyone, we've got some important news to share about Run #2.

**Good news:** we're expecting an initial set of wafers from Global Foundries soon and there are enough wafers for people to get roughly 100-200 dies from this initial batch. These will be diced as normal, with bare die shipping and COB packaging happening soon after.

**Bad news:** the remaining wafers are delayed until sometime in 2027. No exact date yet, but we will update you when we can.

We don't expect this delay to have any impact on the deadlines or timeline of Run #3, so please rest assured if you're building a project for that!
