To give some background:
TQVA/TQVB/TQVC were on run 1 and are identical designs, one in each of the quarter and half slot types. It’s a fairly minimal change over the Tiny Tapeout version, so the main IO is 8 inputs and 8 outputs (direction fixed), though UART and audio are broken out to separate pins.

I’ve proven TQVC works on a simpler host board which has the flash and RAM on a PMOD as in Tiny Tapeout. I designed a CoB for TQVA which matches the pinout of TQVC, and I believe I will very soon have 80 TQVA CoBs to test.

The design itself has peripherals for UART, SPI, PWM, SNES gamepads via the TinyTapeout PMOD, VGA out through the TinyTapeout PMOD, a couple of synths for audio, a couple of different programmable IO type blocks, and some other unusual peripherals from the Tiny Tapeout peripheral competition. It should make a decent platform for retro style games (but compiled with a modern toolchain).


[2026-11-18 9:31 a.m.] rebelmike
On run 2 there were two new versions of TinyQV:
TQVD has an attempt at HDMI output, giving an 80x30 text mode with a scrollable full screen buffer (no need to race the beam!). The font has 32 programmable characters. The same display driver can also output VGA. IO is more flexible, GPIO can fully configure the 16 GPIO pins.

TQVE is an experiment with only 17 pads. That means it only has 6 GPIO, but it has a lot more on board scratch RAM. It also has a USB CDC peripheral, which will hopefully allow a serial console without needing an external UART adapter.

Both TQVD and TQVE use Tholin’s new cell library
